About CardDemo Python Edition

COBOL to Python Translation

CardDemo is a comprehensive credit card management system originally written in COBOL for IBM mainframes.

Original: 30,175 lines of COBOL across 44 programs, using CICS for transactions, VSAM for data storage, BMS for screens, JCL for batch processing, and RACF for security.

Python Edition: Faithful translation of all 18 core business operations to Python, with 49 passing tests. Fixes 14 bugs identified in the original COBOL source code.

Source: aws-samples/aws-mainframe-modernization-carddemo
